# Tick AM-006-001: Codex Exec Adapter

Date: 2026-05-15

## Result

Implemented a local non-interactive Codex exec adapter for prepared run folders.

## Changes

- Added `backend/app/agents/codex_exec.py`.
- Added configurable Codex exec settings:
  - `CODEX_EXEC_BINARY`
  - `CODEX_EXEC_TIMEOUT_SECONDS`
  - `CODEX_EXEC_SANDBOX`
  - `CODEX_EXEC_JSON_EVENTS`
- Adapter invokes `codex exec` with an explicit run-folder working directory.
- Captures sanitized command metadata, exit code, stdout, stderr, start/end timestamps, duration, and failure reason.
- Writes execution logs to:
  - `runs/<run_id>/logs/codex_exec.json`
  - `runs/<run_id>/logs/codex_exec.jsonl`
- Optionally persists run status and audit records when constructed with a DB session.
- Sanitizes the default environment forwarded to Codex and fingerprints the prompt in persisted command metadata.
- Treats stdout/stderr as execution logs only. Importable agent output remains files under `output/` validated by the existing import path.
