# Archive

This directory stores completed Automode tick summaries.

Use one file per completed tick:

```text
archive/tick-002-001.md
```

Each archive entry should include:

- Tick objective.
- Roles used.
- Files changed.
- Tests run and result.
- Review result.
- Follow-up backlog or bug IDs.
- Commit hash if committed.

The archive is memory for future agents. Keep it factual and concise.
