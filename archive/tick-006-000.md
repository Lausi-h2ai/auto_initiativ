# Tick AM-006-000: Codex Runtime Bridge ADR

Status: done

## Summary

Documented the Codex runtime bridge decision in `adr/0002-codex-runtime-bridge.md`.

## Decision

The project supports two Codex runtime modes:

- Interactive tmux chat mode for dashboard onboarding chat.
- File-output worker mode for structured non-chat agent tasks.

The backend remains the source of truth for transcript, run state, validation, promotion, gates, and audit logs. Codex output that can affect later workflow state must be written to `output/` files and schema validated before import.

## Safety

- No Gmail, email adapter, send path, OpenAI API dependency, or autonomous action was added.
- Pane capture is transcript/log material only.
- Safety-relevant state remains backend-validated JSON files.

## Verification

Documentation-only tick. No test run required.
