# AM-003-001: Reconcile Gate Status Schema And Docs

Status: `done`
Date: 2026-05-14

## Objective

Align the imported `gate_result.json` contract with `docs/SAFETY_GATES.md` before executable gate work begins.

## Changes

- Updated `schemas/gate_result.schema.json` to allow only gate statuses: `passed_evaluate_only`, `blocked`, `needs_review`, and `reserved_for_send`.
- Updated the Pydantic `GateResult` model to match the JSON Schema.
- Updated valid gate result fixtures from `passed_dry_run` to `passed_evaluate_only`.
- Added schema and Pydantic tests that accept valid gate statuses and reject `passed_dry_run`, `reserved`, `sent`, and `send_failed`.
- Left reservation and outreach record statuses unchanged because those belong to reservation/outreach persistence, not gate results.
