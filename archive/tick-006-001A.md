# Tick AM-006-001A: Interactive Codex Tmux Chat Adapter

Status: done

## Summary

Implemented a backend adapter for long-running interactive Codex onboarding chat through tmux.

## Changes

- Extended `backend/app/agents/codex_tmux.py` with pane command detection, interactive Codex startup, control-key sending, and pane reset.
- Added `backend/app/agents/onboarding_chat.py` with:
  - start/attach behavior,
  - configured-repository trust prompt handling,
  - message routing through the tmux bridge,
  - best-effort latest assistant reply extraction from pane capture,
  - durable JSONL transcript logging under `runs/<run_id>/logs/onboarding_chat.jsonl`,
  - cancellation logging,
  - session reset logging.
- Added fake-runner/fake-bridge tests for tmux command construction and onboarding chat adapter behavior.

## Safety

- The adapter only controls tmux and writes transcript logs.
- Pane capture is transcript/log material only and is not safety-critical state.
- No Gmail, email adapter, send path, OpenAI API dependency, database mutation path, or autonomous irreversible action was added.
