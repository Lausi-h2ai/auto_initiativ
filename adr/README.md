# Architecture Decision Records

Use this directory for decisions that affect architecture, persistence, safety, migrations, adapters, or long-term workflow.

Recommended filename:

```text
adr/0001-short-title.md
```

Recommended structure:

```text
# ADR-0001: Title

## Status

Proposed | Accepted | Superseded

## Context

## Decision

## Consequences

## Alternatives Considered
```

Create an ADR when a tick changes default stack assumptions, database strategy, safety gate semantics, email adapter policy, or agent/backend boundaries.
