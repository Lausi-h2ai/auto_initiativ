# AM-002-006: Import Valid Outputs Into Domain Tables

Status: `done`
Date: 2026-05-14

## Objective

Normalize schema-valid imported run outputs into Phase 2 domain tables while preserving Phase 1 raw import records and auditability.

## Changes

- Added `DomainNormalizationService` for dependency-ordered import-to-domain normalization.
- Integrated domain normalization into `RunImportService` only after all expected JSON outputs pass schema validation.
- Persisted valid imported outputs into user profile, master CV profile, policy, company, contact, fit evaluation, email draft, send intent, and imported gate result records.
- Preserved raw `ImportedFile` and `ValidationResult` rows as the import audit source.
- Added deterministic handling for schema-valid unresolved references: store external IDs, leave missing FKs null, mark send intents as `needs_review`, and audit `unresolved_references_present`.
- Added reimport cleanup for prior domain rows belonging to the same run before replacing imported files.
- Added import-domain normalization tests.
