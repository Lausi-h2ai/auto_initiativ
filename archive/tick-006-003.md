# Tick AM-006-003: Run Folder Generator

Date: 2026-05-15

## Result

Implemented deterministic backend run-folder generation for Codex exec tasks.

## Changes

- Added `backend/app/agents/run_folder.py`.
- Added `RunFolderSpec`, `RunInputFile`, `RunFolder`, and `RunFolderGenerator`.
- Generator creates:
  - `runs/<run_id>/input/`
  - `runs/<run_id>/output/`
  - `runs/<run_id>/logs/`
  - `runs/<run_id>/task.md`
  - `runs/<run_id>/instructions.md`
  - `runs/<run_id>/prompt.md`
  - `runs/<run_id>/manifest.json`
- Manifest is deterministic and includes input file hashes, expected output files, paths, metadata, and generator version.
- Generated folders can produce a `CodexExecRequest` for `backend/app/agents/codex_exec.py`.
- Optional DB session persistence records a prepared `Run` and `run_folder_prepared` audit log.
- Guardrails reject unsafe relative paths, secret-like content, and explicit external sending capabilities.
- Text writes force LF newlines for reproducible hashes and sizes across platforms.
