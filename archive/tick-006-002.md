# Tick AM-006-002: Dashboard Onboarding Chat Page

Date: 2026-05-15

## Result

Implemented the dashboard onboarding chat page backed by the interactive tmux Codex chat adapter.

## Changes

- Added onboarding chat API contracts and endpoints:
  - `GET /onboarding/chat/{run_id}/transcript`
  - `POST /onboarding/chat/{run_id}/start`
  - `POST /onboarding/chat/{run_id}/messages`
  - `POST /onboarding/chat/{run_id}/finish`
- Wired the endpoints to `OnboardingCodexChatAdapter` through configurable tmux/Codex settings.
- Added the finalization instruction that asks Codex to write `runs/<run_id>/output/user_profile.json`.
- Added `onboarding_chat` as a narrow import type expecting only `user_profile.json`.
- Updated domain normalization so a user-profile-only onboarding run creates a candidate `UserProfileSnapshot` without requiring full outreach output files.
- Added an Onboarding section to the dashboard with run selection, session start, transcript reload, message posting, and finish controls.
- Kept pane capture and transcript data as log/review material only. Importable state still comes from schema-validated files under `output/`.
